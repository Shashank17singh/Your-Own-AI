# Brag Plan: Your-Own-AI

## What is this app?

Your-Own-AI is a C++ vector database that combines HNSW, KD-Tree, and brute-force search with a fully local Ollama-powered RAG workflow.

## The angle

**Your documents, your models, your answers.** Start with a field of semantic vectors, then make the local pipeline tangible: text becomes 768 dimensions, HNSW retrieves the useful pieces, and a local model gives the answer.

## Hook (first 2–3 seconds)

`YOUR DOCS. YOUR AI. LOCAL.` types over a glowing semantic-space grid while colored vector clusters wake up.

## Key moments (the middle)

- The 2D PCA scatter plot resolves into four semantic clusters.
- A document named “Graph Algorithms Notes” becomes a `768D` embedding and enters the HNSW index.
- A question retrieves three source chips before a local answer streams in.

## Outro / punchline

`SEARCH. RETRIEVE. REASON.` settles beneath the Your-Own-AI wordmark.

## User flow worth showing

Paste a document → embed and insert it into the local HNSW index → ask a question → inspect retrieved context and receive an Ollama-generated answer.
